# Wireframes

Dokumen ini berisi deskripsi low fidelity wireframe untuk layar mobile dan admin web. Wireframe bersifat struktural, belum menentukan visual final.

## 1. Mobile App Wireframes

### Splash

Struktur:

- Center logo SiTeknisi.
- Brand name.
- Loading indicator kecil.
- Background solid terang.

### Onboarding

Struktur:

- Area ilustrasi atau foto layanan servis.
- Headline singkat.
- Body copy 1 sampai 2 baris.
- Indicator halaman.
- CTA `Mulai`.
- Link `Lewati`.

### Guest Home

Struktur:

- App bar dengan logo dan tombol login.
- Search bar layanan.
- Section kategori populer.
- Service category grid 2 kolom.
- Banner join Teknisi.
- Bottom area CTA login jika user mencoba request.

### Service Categories

Struktur:

- App bar title.
- Search input.
- Filter chips.
- Grid kategori.
- Empty state jika kategori tidak ditemukan.

### Service Detail
