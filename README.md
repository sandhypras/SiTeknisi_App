# siteknisi_apps

Platform marketplace servis teknisi elektronik berbasis Flutter & Supabase.

## 🚀 Quick Start

### Mode Mock (Tanpa Backend)
```bash
flutter pub get
flutter run
```

### 🚀 Cara Jalankan dengan Supabase

```bash
# Android
run_android_supabase.bat

# Windows Desktop
run_with_supabase.bat

# List available devices
list_devices.bat
```
